about

MiniDL is a deep learning library written only in Java: tensors, backpropagation, convolutions, ResNet, LSTM, transformers, a model server. This page is its handwriting demo. The page draws; the Java program recognises.

Run it: ./run-web.sh or java -jar minidl-1.5.1.jar web, then open http://localhost:8080. Source and instructions: github.com/manishn1877/minidl-java.
