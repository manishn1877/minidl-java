Neural network in Java (Man-JAVA)

MiniDL is the library: a neural network toolkit in pure Java with no outside machine learning code. The handwriting recognition model below is one application built from its parts: the same layers, trainer, quantizer, file format and web server.

Library partWhat it gives
Tensors and mathsmatmul, broadcasting, reshape views, softmax, multi-thread kernels
LayersDense, Conv2D, pooling, BatchNorm, LayerNorm, Dropout, LSTM, attention, Residual, Embedding
LearningAdam, AdamW, SGD, RMSProp, schedules, clipping, early stopping, autograd
Deployint8 / int4 / bfloat16, binary files, safetensors, HTTP server

Handwriting recognition model: the network

A 28×28 picture goes through two convolution + pooling stages, then dense layers to 10 scores (0–9). Total: 27,562 weights (107.7 KB as float32).
